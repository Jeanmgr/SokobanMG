# SokobanMG
En este proyecto se desarrolló un juego llamado Sokoban utilizando Python, con el propósito de poner en práctica los conocimientos adquiridos en la carrera de TIC's. El juego funciona desde la terminal y consiste en mover un personaje para empujar cajas hasta colocarlas sobre las metas, evitando las paredes y los movimientos incorrectos.
